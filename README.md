# KawaiiPinball

ドット絵のかわいいキャラクターボールが、ネオンに光る盤面を転がる縦画面の 2D ピンボールです。
ボール 3 個が尽きる前に、ステージごとの目標スコアを超えればクリア。全 3 ステージを順番に解放していきます。

このリポジトリは Android 版アプリ（APK）の配布専用です。

## ダウンロード

**[最新版をダウンロード（Releases）](https://github.com/kanpanda/KawaiiPinball-releases/releases/latest)**

ページの「Assets」にある `KawaiiPinball-x.y.z.apk` をダウンロードしてください。

### 動作環境

- Android 7.1 以上、64bit（ARM64）端末
- 縦画面専用。Pixel 8a（1080×2400）で動作確認しています。画面比率が違う端末では、表示が少しずれることがあります

## インストール方法

Google Play 以外から配布しているため、はじめに「提供元不明のアプリ」のインストールを許可する必要があります。

1. Android 端末のブラウザ（Chrome など）で上の「最新版をダウンロード」を開き、APK をダウンロードする
2. ダウンロード完了の通知、または「ファイル」アプリから APK をタップする
3. 「このソースからのアプリのインストールは許可されていません」と表示されたら **設定** をタップし、そのアプリ（Chrome / ファイル など）の **「この提供元のアプリを許可」** を ON にして戻る
4. **インストール** をタップ → 完了したら **開く**

- Play プロテクトの確認画面が出た場合は、内容を確認のうえ「インストール」（または「スキャンせずにインストール」）を選んでください。
- 許可の設定は、あとから「設定 → アプリ → 特別なアプリアクセス → 不明なアプリのインストール」で OFF に戻せます。

## 遊び方

### 画面の流れ

```text
タイトル ──START──▶ ステージ選択 ──ステージをタップ──▶ ゲーム ──▶ リザルト
                        ▲                                          │
                        └──────── STAGE SELECT / NEXT STAGE ◀──────┘
```

1. **タイトル**: `START` をタップ
2. **ステージ選択**: 遊ぶステージのカードをタップ。`LOCKED` のステージは、ひとつ前のステージをクリアすると解放されます。カードには `TARGET`（クリアスコア）と `BEST`（自己ベスト）が表示されます
3. **ゲーム**: 下の操作で遊びます
4. **リザルト**: `STAGE CLEAR` なら `NEXT STAGE`、`TRY AGAIN` なら `RETRY`。`STAGE SELECT` でステージ選択に戻ります

### 操作

| 操作 | 動作 |
| --- | --- |
| 画面のどこかを押して、離す（ボールが発射レーンにあるとき） | ボールを発射。**長く押すほど強く**打ち出し、約 1 秒で最大。弱すぎるとレーンを戻ってくるので、もう一度打てます |
| 画面の **左半分** をタッチ / 押しっぱなし | **左フリッパー** を上げる |
| 画面の **右半分** をタッチ / 押しっぱなし | **右フリッパー** を上げる |
| 右上の `II` ボタン | ポーズ |

- フリッパーは指を離すと下がります。両手で左右同時に押しても OK です。
- ポーズ画面では `RESUME`（再開）、`RETRY`（やり直し）、`STAGE SELECT`（ステージ選択へ）、`SE: ON/OFF`、`BGM: ON/OFF` が選べます。音の設定はアプリを終了するとリセットされます。

### ルール

- ボールは **3 個**。フリッパーの下に落ちると 1 個減ります。落ちたボールは盤面の下のたまり場へ転がって列に戻り、1 秒後にたまり場の先頭のボールが発射レーンへ押し出されます（たまり場のボールは見た目の演出で、残り数とは関係ありません）。
- 3 個目のボールを失った時点で、**累計スコアがそのステージの TARGET 以上ならクリア**です。TARGET に届いてもすぐにはクリアにならず、最後まで遊んで達成率（スコア ÷ TARGET）を競います。
- クリアすると次のステージが解放され、自己ベストが保存されます。

### 得点

| 盤面のパーツ | 見た目 | 得点 |
| --- | --- | --- |
| バンパー | 黄色の丸い顔 | 100 点。当たると弾き飛ばされる |
| スリングショット | フリッパー上の三角 | 斜めの面に当たると 50 点。面に対して垂直に弾き返される（他の面は普通に跳ね返るだけ） |
| ドロップターゲット | 紫の四角い板（3 枚 1 組） | 1 枚 200 点。**3 枚すべて倒すと +1,000 点** のボーナス（1 秒後に復活） |
| トップレーン | 盤面最上部のレーン（3〜4 本） | 通過で 300 点。**全レーンを通過すると +1,500 点** のボーナス（1 秒後にリセット） |
| スピナー | 発射レーン内の羽根 | 1 回転ごとに 20 点。発射が速いほどよく回る |

### ステージ

| # | 名前 | TARGET | 特徴 |
| --- | --- | --- | --- |
| 1 | Neon Candy | 4,000 | バンパー 3 個、ドロップターゲット 3 枚、トップレーン 3 本。最初から遊べる |
| 2 | Mint Soda | 8,000 | バンパー 4 個（菱形）、ドロップターゲットが左右 2 組 |
| 3 | Berry Galaxy | 15,000 | バンパー 5 個（W 字）、ドロップターゲット 2 組、トップレーン 4 本 |

### コツ

- しっかり溜めて（約 1 秒）発射すると、ボールは盤面上部のデフレクターで左へ跳ね、トップレーンを通ります。まずはここで 300 点を確実に取りましょう。軽めに打つと、レーンの出口から盤面の右側へ落ちます。
- バンパーの間でボールが跳ね回っている間は連続で得点が入ります。フリッパーで上部中央へ打ち返すのが高得点の近道です。
- ドロップターゲットは 3 枚コンプリートのボーナス（+1,000）が大きいので、残り 1 枚のときは狙って打ちましょう。
- 両フリッパーを押しっぱなしにするとボールを受け止めて落ち着かせられます（トラップ）。狙いを定めてから片方を離して打ち出せます。

## データについて

自己ベストとステージの解放状態は、端末の中にだけ保存されます。消したいときは「設定 → アプリ → KawaiiPinball → ストレージ → ストレージを消去」を行ってください。アンインストールしても消えます。
